# Product images

Product image URLs are centralized in `app.js` under `storeConfig.products`.

When final photography is available, place these files in this directory and replace each corresponding URL in `app.js`:

- `dog-product-1.jpg`
- `dog-product-2.jpg`
- `dog-product-3.jpg`
- `cat-product-1.jpg`
- `cat-product-2.jpg`
- `cat-product-3.jpg`

Use the paths `./assets/dog-product-1.jpg` and so on. The gallery, cart and checkout will update automatically.
